# Une méthode en quatre étapes pour lire les avis

Un avis signale une expérience rapportée. Il ne suffit pas, à lui seul, à établir une cause ou la fréquence réelle d’un problème. La méthode ci-dessous sert à décider **quoi vérifier**, pas à produire une statistique représentative.

## 1. Définir un lot comparable

Fixez une période, un établissement et une source. Notez combien d’avis sont exploitables dans ce lot. Ne mélangez pas un mois de Google avec un an d’une autre plateforme pour calculer un pourcentage unique.

## 2. Coder les thèmes sans forcer les catégories

Attribuez à chaque avis les thèmes qu’il décrit précisément : attente, bruit, propreté, accueil, etc. Un même avis peut citer deux thèmes. Gardez donc le **nombre d’avis distincts** comme dénominateur ; ne présentez pas la somme des thèmes comme un nombre d’avis uniques.

## 3. Vérifier avant de conclure

Pour un thème récurrent, cherchez un fait vérifiable : date, équipe présente, mesure interne, échange client autorisé. Conservez aussi les avis contradictoires. Une hausse du nombre de mentions peut refléter un changement de volume d’avis, de canal ou de clientèle ; ce n’est pas automatiquement une dégradation du service.

## 4. Décider et fermer la boucle

Écrivez une fiche courte : **signal → vérification → responsable → action → date de contrôle**. Si la vérification ne confirme rien, dites-le. Si elle confirme un problème, mesurez l’effet de l’action sur une période comparable, sans promettre que la note changera.

<div class="note"><strong>Exemple fictif :</strong> sur 12 avis d’un restaurant pendant un mois, 3 mentionnent l’attente. On peut écrire « 3 avis sur 12 mentionnent l’attente dans ce lot ». On ne peut pas écrire « 25 % de tous les clients ont attendu ». Le responsable vérifie les heures de service citées avant de modifier l’organisation.</div>
